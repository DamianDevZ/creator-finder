Creator Finder — User Flow

flowchart TD
  A["User pastes Steam link
or searches game name"] --> B["Analyze game"]
  B --> C["Fingerprint preview
game info · tags · similar games"]
  C --> D{"User edits search base?
(add/remove tags or games)"}
  D -->|Yes| E["Steam autocomplete search
update tag/game lists"] --> C
  D -->|No| F["Find creators"]

searches similar-game videos"]

latest 10 uploads per channel"]
  H --> I["Ranked results table
score · subs · avg views · covers
language · notes · email"]
  I --> J["User filters:
sub range · has email · language"]
  J --> K["Optional: AI notes fill in
per channel"]
  I --> L["User contacts creators
(outreach emails)"]
