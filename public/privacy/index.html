Privacy Policy — Creator Finder

Creator Finder uses YouTube API Services. By using it you also agree to the
YouTube Terms of Service and the
Google Privacy Policy.

  • Data accessed: read-only public data via the YouTube Data API v3
(video/channel metadata, statistics) and public Steam store information.
  • Data stored: API responses are cached in a local `cache.json` file on the
user's machine to reduce API quota usage. No personal data is collected.
  • No accounts, no tracking: the tool has no user accounts, analytics,
or telemetry of any kind.
  • No third-party sharing: data is never transmitted to any server other
than the official Google/Steam API endpoints needed to fulfill requests.

Contact: via the GitHub repository issues page.
